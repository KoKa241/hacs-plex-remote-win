# Plex PC Remote

Локальный пульт для **Plex HTPC на Windows 10/11**: Python-сервер на компьютере + интеграция Home Assistant + карточка пульта + экспорт телевизора в Apple Home через HomeKit Bridge.

**Питание управляет только приложением Plex.** Первое нажатие открывает Plex HTPC, следующее закрывает. Выключения, сна, перезагрузки и Wake-on-LAN в проекте нет. Plex Media Server не закрывается.

## Новое в 1.3.0

Пульт разделён на вкладки **«Пульт Plex»** и **«Мышь и клавиатура»**. По умолчанию открываются обычные кнопки Plex; тачпад на этой вкладке не отображается. На второй вкладке доступны мышь, ввод текста и клавиши, включая отдельную **Windows / Win** для открытия меню «Пуск». Клавиши Windows теперь правильно размещены в разделе мыши.

Обновите HACS и Python-сервер на Windows, перезапустите оба и обновите страницу. Новая кнопка Win требует сервера 1.3.0.

## Новое в 1.2.1:

- Вернули постоянно видимый кнопочный пульт; добавили отдельные кнопки рядом с площадкой Plex.
- Перемещение мыши использует текущие координаты и `SetCursorPos`; ошибки Windows теперь видны в карточке. Сервер должен работать в интерактивном сеансе вошедшего пользователя, не как служба.

## Новое в 1.2.0: тачпад и клавиатура

В **Plex пульт** появилась сенсорная площадка с переключателем режимов:

- **Жесты Plex:** свайп — одна стрелка в выбранном направлении; короткое касание — OK/Enter; касание двумя пальцами — назад/Esc. Курсор Windows не перемещается. Порог свайпа — 32 px, касания — 10 px; длинное удержание не считается кликом. Вибрация — только если браузер/телефон её поддерживает.
- **Мышь Windows:** один палец перемещает курсор относительно текущего положения; короткое касание — левый клик; два пальца прокручивают, а короткое касание двумя пальцами — правый клик. Есть отдельные кнопки левого/правого клика. Режим работает и при закрытом Plex, не переключает фокус на него. Перетаскивание с удержанием кнопки пока не реализовано.
- **Текст:** выберите нужное поле на компьютере, напечатайте текст на телефоне, нажмите «Отправить текст». Поддерживается Unicode (включая кириллицу и emoji), максимум 2000 символов. Текст очищается после подтверждения; при ошибке сохраняется для проверки. Ввод пакетный, не посимвольное зеркалирование редактора телефона. Переносы строк отправляются как Enter.
- **Клавиши:** Esc, Enter, Backspace, Tab, Delete, Alt+Tab, **Alt+F4** (обычное закрытие активного приложения), **Ctrl+Shift+Esc** (диспетчер задач), Win+D, Ctrl+A/C/V. «Вставить» использует буфер обмена **Windows**, не телефона. Alt+F4 не принудительно завершает зависшую игру; у приложения может появиться запрос сохранения. На рабочем столе это сочетание может открыть системный диалог завершения работы — само подтверждение не отправляется.

Начиная с 1.3.0 обычный кнопочный пульт и мышь размещены на отдельных вкладках; режим жестов Plex в карточке больше не показывается. HomeKit продолжает управлять телевизором; мышь/ввод текста доступны в интерфейсе HA, не в Apple Remote.

### Обновление до 1.2.1

1. Остановите Windows-сервер, обновите файлы (`git pull --ff-only` или свежий ZIP с сохранением `server/config.json` и `.venv`), запустите сервер снова.
2. Обновите интеграцию через HACS и перезапустите HA. Обновите страницу или закройте/откройте приложение HA, чтобы загрузился новый JS пульта.
3. Откройте **Plex пульт → Мышь Windows**. Если появится сообщение об обновлении сервера, на Windows ещё работает старая версия. При переходе с 1.1.0 раскладка Plex не меняется; при переходе с 1.0.0 выполните также перезапуск Plex, описанный ниже.

Дополнительные порты открывать не нужно. Браузер использует существующий авторизованный WebSocket Home Assistant; HA проверяет права управления выбранной remote-сущностью и передаёт команды в `/api/input` Windows-сервера через постоянные HTTP-соединения. Движения объединяются в небольшие пакеты, очередь ограничена, неотправленные события сбрасываются при смене режима/компьютера и потере фокуса. Автоматического повтора текста и кликов после сетевой ошибки нет. Токен Windows остаётся на HA.

Площадка не передаёт изображение рабочего стола. Windows должен быть разблокирован. SendInput не обходит UAC и не управляет окнами с более высокими правами; некоторые игры с raw input/античитом могут игнорировать синтетический ввод. Ctrl+Alt+Del не поддерживается. Текст не записывается сервером в журнал, но отправляется в активное окно — включая терминал, если именно он выбран.

## Обновление с 1.0.0 до 1.1.0

Обновите **обе части**: HACS не обновляет Python-сервер на Windows.

1. На Windows остановите сервер (Ctrl+C в консоли, либо `Stop-ScheduledTask -TaskName "Plex PC Remote"`).
2. В папке проекта выполните `git pull --ff-only`. Если устанавливали ZIP, скачайте свежий ZIP репозитория и замените файлы, **сохранив `server/config.json` и `.venv`**.
3. Запустите сервер снова: `.\.venv\Scripts\python.exe -m server.app`, либо `Start-ScheduledTask -TaskName "Plex PC Remote"`.
4. Сервер сам установит новую раскладку. **Закройте и снова откройте Plex** (можно кнопкой питания пульта). Это нужно один раз, чтобы Plex прочитал новые клавиши.
5. В HACS скачайте обновление интеграции 1.1.0 (при необходимости меню → «Скачать повторно», ветка main), перезапустите HA и обновите страницу браузера/приложения.
6. Откройте **«Plex пульт» в боковом меню**. Он появляется автоматически и содержит все кнопки. Старую стандартную карточку медиаплеера можно убрать с панели.
7. В пульте нажмите **«Добавить в Apple Home»** от пользователя-администратора HA, затем отсканируйте QR-код HomeKit на iPhone.

В 1.0.0 F11 для громкости конфликтовал с полноэкранным сочетанием Plex. В 1.1.0 используются F13–F24 и Ctrl+F13–F16, профиль автоматически проверяется и устанавливается. Если Plex ещё использует старый профиль, команды блокируются до перезапуска приложения. Кнопка «Пуск / Пауза» в новом пульте отправляет `play_pause` при каждом нажатии, независимо от состояния процесса.

## Что есть

- Стрелки, OK/Enter, назад/Esc, главная, информация.
- Play/Pause, отдельные Play и Pause, Stop, перемотка ±10 секунд, предыдущий/следующий элемент.
- Громкость **внутри Plex**, mute, субтитры, смена аудиодорожки, полный экран.
- Реальный статус процесса, обновление каждые 5 секунд и сразу после команды.
- Настройка URL и токена через интерфейс HA, повторная настройка при изменении IP/токена.
- `media_player` с классом `tv` и `remote`, объединённые в одно устройство.
- Автоматическая панель «Plex пульт» со стрелками, OK, Esc, перемоткой и отдельной кнопкой Play/Pause.
- Кнопка создания HomeKit TV аксессуара, без ручного YAML.
- Кнопки навигации Apple Remote обрабатываются автоматически, только для соответствующей TV-сущности.

Это управление клавиатурой, поэтому название фильма, позиция, фактическая пауза и уровень громкости не считываются. Сущность показывает `on`/`off`, а при недоступном сервере — `unavailable`. Уровень громкости и состояние mute не выдумываются: используются кнопки. При passthrough звука громкость может регулироваться только ресивером.

## 1. Windows-сервер

Нужны Python 3.11+ и **Plex HTPC**. Обычный Plex for Windows и браузерная версия этим профилем не поддерживаются. Запустите Plex HTPC хотя бы один раз, войдите в аккаунт и закройте приложение перед установкой раскладки.

Скопируйте проект, например, в `C:\PlexRemote`. В PowerShell:

```powershell
cd C:\PlexRemote
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r server\requirements.txt
.\.venv\Scripts\python.exe -m server.setup
.\.venv\Scripts\python.exe -m server.app
```

Если Plex установлен в другом месте:

```powershell
.\.venv\Scripts\python.exe -m server.setup --plex-path "D:\Apps\Plex HTPC\Plex HTPC.exe"
```

Установщик создаёт `server/config.json` с уникальным ID компьютера и случайным API-токеном. Скопируйте токен в настройку интеграции HA. Файл исключён из Git; не публикуйте его. При повторном запуске setup существующий конфиг сохраняется — путь тогда меняйте непосредственно в нём.

Setup устанавливает `server/keyboard.json` в `%LOCALAPPDATA%\Plex HTPC\inputmaps\keyboard.json`. Существующий файл сохраняется рядом как `keyboard.backup-….json.bak`. Используется своя раскладка: F13–F24 и Ctrl+F13–F16 для команд, стрелки/Enter/Esc для навигации. Она заменяет пользовательские сочетания; при необходимости объедините их вручную с резервной копией. После изменения раскладки перезапустите Plex. Сервер также устанавливает и проверяет этот профиль при каждом запуске; повторно запускать setup при обновлении не нужно.

Разрешите входящий TCP **8321** только от IP Home Assistant. Пример команды в PowerShell администратора (замените IP):

```powershell
New-NetFirewallRule -DisplayName "Plex PC Remote from HA" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8321 -RemoteAddress 192.168.1.20 -Profile Private
```

API использует Bearer-токен и обычный HTTP: это вариант для доверенной домашней сети. Не пробрасывайте порт в интернет. Для внешнего доступа используйте доступ к самому Home Assistant/VPN. Интеграция также принимает HTTPS URL, если вы настроите TLS-прокси.

### Автозапуск

Сначала проверьте запуск сервера в консоли. Затем остановите его Ctrl+C и выполните от обычного пользователя:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\register-startup.ps1
Start-ScheduledTask -TaskName "Plex PC Remote"
```

Задача запускается **при входе пользователя**. Сервер должен работать в интерактивном сеансе того же пользователя, что и Plex, с одинаковыми правами; не устанавливайте его как Windows Service. Заблокированный экран, UAC и отключённый RDP-сеанс могут препятствовать управлению. Если Windows запрещает активацию окна, команда вернёт ошибку; активируйте Plex локально и повторите.

Удалить автозапуск:

```powershell
Unregister-ScheduledTask -TaskName "Plex PC Remote" -Confirm:$false
```

При закрытии сервер сначала отправляет WM_CLOSE окнам выбранного Plex HTPC.exe. Через 5 секунд он завершает оставшиеся процессы **этого же исполняемого файла**, если приложение не закрылось самостоятельно.

## 2. Home Assistant

Поддерживаемая минимальная версия HA: **2025.6**.

### Сейчас: ручная установка

1. Скопируйте `custom_components/plex_pc_remote` в `/config/custom_components/plex_pc_remote` на HA.
2. Перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → **Plex PC Remote**.
4. Введите `http://IP_КОМПЬЮТЕРА:8321` и токен из `server/config.json`.
5. В устройстве появятся TV и Remote. Обычно их ID: `media_player.plex_pc_tv` и `remote.plex_pc_remote`; проверьте фактические ID.

Закрепите IP компьютера в DHCP. Изменить адрес/токен можно в меню интеграции → Перенастроить. При недоступном компьютере HA повторяет подключение, но не включает компьютер.

### Установка через HACS

1. В HACS откройте меню → Пользовательские репозитории.
2. Добавьте `https://github.com/KoKa241/hacs-plex-remote-win` с типом **Integration**.
3. Найдите **Plex PC Remote**, скачайте и перезапустите Home Assistant.
4. Добавьте интеграцию через Настройки → Устройства и службы, укажите URL Windows-сервера и токен.

Это пользовательский репозиторий HACS; добавление в общий каталог не выполнялось. Windows-сервер устанавливается отдельно: HACS скачивает только интеграцию. Карточку добавьте по инструкции ниже.

## 3. Карточка пульта

После настройки интеграции в боковом меню автоматически появляется **Plex пульт**. Он определяет сущности сам, поддерживает выбор компьютера, показывает ошибки и предупреждает о старом сервере/необходимости перезапустить Plex. Токен Windows API не передаётся в браузер: команды идут через Home Assistant.

Чтобы добавить такой же пульт на вашу панель: Редактировать → Добавить карточку → найдите **Plex PC Remote**. Либо добавьте вручную:

```yaml
type: custom:plex-pc-remote-card
```

Для конкретного компьютера можно указать `entity: remote.plex_pc_remote` и `name: Пульт гостиной`. Используйте фактический ID своей remote-сущности. Карточка поставляется вместе с интеграцией; отдельная установка frontend-репозитория или регистрация ресурса не нужна.

Стандартная карточка `media-control` не является полным пультом: у неё нет крестовины, и она может показывать Play, когда неизвестно фактическое состояние воспроизведения. Используйте новый пульт — его кнопка всегда вызывает `play_pause`.

`examples/remote-card.yaml` сохранён как вариант из стандартных кнопок для ручной настройки. Для него нужно самостоятельно заменить entity_id. Автоматическая боковая панель и новая карточка этого не требуют.

Для автоматизации можно вызвать:

```yaml
action: remote.send_command
target:
  entity_id: remote.plex_pc_remote
data:
  command: back
```

Все команды: `turn_on`, `turn_off`, `toggle`, `focus`, `up`, `down`, `left`, `right`, `select`, `back`, `home`, `info`, `play_pause`, `play`, `pause`, `stop`, `seek_backward`, `seek_forward`, `previous`, `next`, `volume_down`, `volume_up`, `mute`, `subtitles`, `audio`, `fullscreen`.

`num_repeats` поддерживает 1–20 повторов, `delay_secs` — 0–5 секунд; удержание клавиши не поддерживается. Повторы `toggle`/`mute` будут переключать состояние несколько раз, поэтому используйте их осознанно.

## 4. Apple Home / HomeKit

1. Откройте **Plex пульт** от администратора HA и нажмите **Добавить в Apple Home**.
2. Интеграция создаст отдельный HomeKit Bridge в режиме **Accessory**, включающий только вашу TV-сущность. Повторное нажатие не создаёт дубль существующего аксессуара.
3. Откройте уведомление HomeKit с QR-кодом (или Настройки → Устройства и службы → HomeKit Bridge).
4. На iPhone: **Дом → + → Добавить аксессуар**, отсканируйте QR-код.
5. Для стрелок и OK: **Пункт управления → Пульт Apple TV → Plex PC**. Плитка телевизора в приложении «Дом» не показывает полноценную крестовину.

HA и iPhone должны видеть друг друга в локальной сети (mDNS/Bonjour); в Docker нужен корректный сетевой режим HomeKit Bridge. Сопряжение на iPhone выполняется пользователем; кнопка в HA только создаёт аксессуар для сопряжения.

Если TV уже был добавлен через HomeKit Bridge, используйте существующий аксессуар. В качестве альтернативы можно вручную настроить HomeKit Bridge: режим Accessory, единственная сущность `media_player.plex_pc_tv` (фактический ID). YAML-вариант — `examples/homekit.yaml`. Не создавайте второй аксессуар для того же телевизора.

В «Доме» будет телевизор: включение открывает Plex, выключение закрывает. Стрелки, OK, назад и доступные дополнительные кнопки пульта iPhone передаются через события HomeKit. Play/Pause и громкость идут через стандартные действия media_player. Дополнительная автоматизация не требуется. Набор видимых кнопок зависит от iOS; субтитры, дорожки и полный экран доступны в карточке HA. Это не AirPlay-приёмник.

См. [официальную документацию HomeKit Bridge](https://www.home-assistant.io/integrations/homekit/): телевизору нужен режим Accessory; управление пультом доступно в Пункте управления.

## Проверка и диагностика

На Windows проверить API без команды:

```powershell
$config = Get-Content .\server\config.json | ConvertFrom-Json
Invoke-RestMethod http://127.0.0.1:8321/api/status -Headers @{Authorization="Bearer $($config.token)"}
```

- `401`: токен не совпадает.
- `409`: Plex закрыт, не готов или Windows не позволяет отправить ввод.
- `503`: ошибка Windows; смотрите `server/config.log` (журнал с ротацией).
- HA показывает `unavailable`: проверьте сервер, IP, частный профиль сети и firewall.
- Стрелки работают, дополнительные кнопки нет: проверьте установку inputmap и перезапустите Plex HTPC.
- Громкость не меняется: проверьте audio passthrough и управление громкостью ресивера.

Локальные автоматические проверки:

```sh
python -m pip install -r requirements-dev.txt
python -m pytest
ruff check .
npm ci
npm test
```

Тесты проверяют API, авторизацию, запрет посторонних команд, последовательность переключений, отказ отправки клавиш без фокуса, миграцию раскладки и ожидание перезапуска Plex. DOM-тесты запускают настоящий JS-код пульта и проверяют навигацию, повторные Play/Pause, недоступный сервер, ошибки и правильную сущность HomeKit. Реальные Win32-вызовы, Plex HTPC, загрузку в HA и сопряжение с iPhone нужно проверить на целевых устройствах; текущая среда разработки — macOS.

Документация: [Plex HTPC Input Maps](https://support.plex.tv/articles/plex-htpc-input-maps/), [Media player entity](https://developers.home-assistant.io/docs/core/entity/media-player/), [требования HACS](https://www.hacs.xyz/docs/publish/integration/).

Отдельная проверка совместимости с настоящими классами HA 2025.6.3 (в отдельном окружении Python 3.13):

```sh
python -m pip install -r requirements-ha-test.txt
python -m pytest tests_ha -q
```

Она проверяет регистрацию/перезагрузку панели, поиск переименованной TV-сущности, фильтрацию HomeKit-событий, вызов `media_play_pause` из настоящего HomeKit TV-класса и создание Accessory через нативный config flow. Сетевое сопряжение iPhone и клавиши Win32 эта проверка не эмулирует.
